# Сторонние компоненты

## Используются во время работы
- **PySide6 / Qt for Python** — интерфейс. Лицензия: LGPL v3 (или GPL v3 / коммерческая Qt).
  Приложение использует Qt по LGPL: библиотеки Qt лежат отдельными файлами (сборка папкой, onedir),
  их можно заменить. Полный текст LGPL v3: https://www.gnu.org/licenses/lgpl-3.0.html
  Исходники PySide6: https://code.qt.io/cgit/pyside/pyside-setup.git

## Используются только при разработке и сборке (в программу не входят)
- **PyInstaller** — сборка exe. Лицензия GPL v2 с исключением для программ, которые его используют.
- **pytest** — тесты. Лицензия MIT.
- **Inno Setup** — создание установщика. Бесплатная лицензия, в установщик не входит.

Встроенный код приложения не использует нейросетевые модели и внешние API, кроме проверки обновлений
по HTTPS (см. `studio_pro/updater.py`).
