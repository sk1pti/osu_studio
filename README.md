# osu! Studio PRO

Инструмент для мапперов osu!: проверка и правка `.osu` / `.osz`, сборка сетов с авто-лестницей
сложности, тюннер, линтер, работа с референсами и конфигом нейросетевого маппера
(Mapperatorinator).

## Установка
Скачай последний `osu_studio_setup_<версия>.exe` в разделе [Releases](https://github.com/sk1pti/osu_studio/releases)
и запусти. Windows 10/11.

## Запуск из исходников
```
pip install -r requirements.txt
python -m studio_pro
```
Нужен Python 3.10+.

## Сборка
См. [BUILD.md](BUILD.md): сборка папки, установщик Inno Setup, выпуск релиза.

## Ограничения и ответственность
- Инструмент помогает с ручной работой над картой: проверки, правки таймингов и расстояний,
  сборка сета. Перед публикацией карту нужно проверить самому.
- Соблюдай правила сообщества osu! и ranking criteria. Использование инструментов для
  маскировки автоматически сгенерированных карт может быть запрещено в конкретных модах и
  турнирах. Ответственность за соблюдение правил несёт тот, кто публикует карту.
- Программа не содержит и не распространяет музыку, фоны и карты. Авторские права на
  сгенерированные карты, треки и арт принадлежат их создателям.
